# 단군슬롯

따뜻한 미색 바탕에 자체 제작한 슬롯 SVG 5종과 풍경 그림을 사용하는 작은 웹 슬롯 게임입니다.

## 실행

ZIP을 받았다면 먼저 전체 압축을 풉니다. `index.html`을 Chrome, Edge 등 웹브라우저로 열면 됩니다. 설치, 빌드, 서버, 인터넷 연결이 필요하지 않습니다. `assets` 폴더를 포함한 파일들의 상대 위치를 유지해 주세요.

모바일에서도 같은 반응형 페이지를 사용합니다. 모바일 파일 앱의 HTML 미리보기는 JavaScript 실행을 제한할 수 있으므로 웹브라우저에서 열어 주세요. 정적 웹 호스팅에도 폴더 내용 그대로 올릴 수 있습니다.

## 구성

```text
dangun-slot/
  index.html
  style.css
  script.js
  assets/
    mugwort.svg
    garlic.svg
    tiger.svg
    bear.svg
    dangun.svg
    myth-landscape.svg
  README.md
```

모든 그림은 이 게임을 위해 직접 작성한 SVG입니다. 외부 이미지, 폰트 다운로드, 프레임워크, 게임 실행용 라이브러리를 사용하지 않습니다. 그림을 바꾸려면 같은 파일명의 SVG를 교체하면 됩니다. 권장 viewBox는 `0 0 200 200`이며 그림은 테두리에서 여유를 두고 배치하세요. PNG 등 다른 형식을 쓰려면 HTML 초기 이미지와 JavaScript의 이미지 경로도 함께 바꾸면 됩니다.

## 조작과 결과

`돌리기`를 누르면 그림 띠가 위에서 아래로 굴러가다가 서서히 느려집니다. 세 칸은 1.0초, 1.2초, 1.4초에 순서대로 멈춥니다. 일반 성공·실패 화면은 약 1.6초간 표시합니다. 단군 3개로 성공하면 신단수 풍경이 나타나고 단군이 부드럽게 등장하는 전용 컷신을 약 3.2초간 보여 줍니다. `계속하기` 또는 Esc로 바로 닫을 수도 있습니다. 회전과 결과 화면 표시 중에는 중복 입력을 받지 않습니다. 키보드 Tab으로 버튼을 선택한 뒤 Enter 또는 Space로도 플레이할 수 있습니다.

산과 동굴, 신단수 풍경을 소박한 SVG로 더했습니다. 슬롯 안의 그림 5종과 같은 색감으로 맞추었으며 번쩍임이나 화면 흔들림은 없습니다.

운영체제의 동작 줄이기 설정을 켜면 빠른 그림 교체를 생략하고 같은 시간에 최종 그림만 표시합니다. 단군 컷신도 이동이나 페이드 없이 완성된 장면으로 보여 줍니다. 화면 흔들림, 점멸, 소리, 결제, 베팅, 유료 재화, 현금성 보상, 플레이 횟수 제한은 없습니다.

## 확률

PC에서는 게임 오른쪽, 모바일에서는 게임 아래에 확률표를 표시합니다. 표의 비율은 천장을 제외한 일반 회전에서 같은 그림 3개가 나올 확률입니다. 천장 회전은 단군 100%입니다. 추첨·확률표·시뮬레이션은 하나의 설정값을 공유합니다.

각 회전 시작 시 `decideSpin()`이 천장을 먼저 확인합니다. 천장 대상이 아니면 아래 규칙의 `decideResult()`로 결과를 결정합니다.

1. `Math.random() < 0.20`이면 3칸 일치입니다.
2. 일치 분기에서 새로운 난수가 `0.10` 미만이면 단군입니다. 따라서 일반 회전 중 단군 성공 확률은 `20% × 10% = 2%`입니다.
3. 나머지 일치는 쑥·마늘·호랑이·곰을 6:6:4:4 가중치로 선택합니다.
4. 불일치 분기는 5종 중 각 칸을 균등 추첨합니다. 세 칸이 모두 같으면 세 칸을 다시 추첨합니다. 따라서 120가지 불일치 조합은 균등하며, 두 칸만 같은 결과도 나올 수 있습니다.

일반 회전 기준 기대 확률은 쑥 5.4%, 마늘 5.4%, 호랑이 3.6%, 곰 3.6%, 단군 2%, 불일치 80%입니다. 일반 회전의 기본 확률은 바뀌지 않으며, 아래의 30회 천장을 추가 적용합니다.

애니메이션은 시간에 따라 그림을 순환 표시할 뿐 난수를 호출하거나 미리 정한 결과를 변경하지 않습니다.

## 단군 30회 천장

- 단군 3개가 나오지 않은 회전을 누적합니다. 다른 그림 3개로 성공해도 횟수가 쌓입니다.
- 단군 없이 29회가 지나면 **30번째 회전은 단군 3개 확정**입니다. 해당 회전에는 난수를 호출하지 않습니다.
- 일반 확률 또는 천장으로 단군 3개가 나오면 누적 횟수는 0으로 초기화됩니다. 단군이 한두 칸에만 나온 것은 초기화 조건이 아닙니다.
- 천장 횟수, 진행 막대와 천장 안내 문구는 화면에 표시하지 않습니다. 내부 보장과 저장 기능은 유지합니다.
- 확정 단군도 자연 당첨과 같은 단군 전용 컷신을 재생합니다.

천장을 포함한 장기 평균 단군 비율은 약 **4.4003%**입니다. 화면의 **2%는 일반 회전의 기본 확률**이며, 천장까지 포함한 최종 발생 비율은 아닙니다. 천장 회전이 추가되므로 전체 성공 비율도 기본 20%보다 높아집니다.

## 횟수 저장

결과와 천장 횟수를 브라우저 localStorage의 `dangun-slot-progress-v1`에 한 번에 저장한 뒤 애니메이션을 시작합니다. 새로고침하면 마지막 결과와 횟수를 복원하며 추가 추첨하거나 컷신을 다시 시작하지 않습니다. 중복 클릭·건너뛰기·Esc·자동 닫힘은 횟수를 추가하지 않습니다.

저장 실패 시에는 회전을 시작하지 않고 ‘저장 다시 시도’를 표시합니다. 같은 페이지에서 재시도하면 이미 정해 둔 결과를 그대로 저장하므로 재추첨하지 않습니다. 저장된 기록을 읽을 수 없거나 손상된 경우에는 임의로 초기화하지 않고 진행을 중단합니다.

같은 브라우저의 같은 저장 영역에서 기록을 유지합니다. 파일 이동, 다른 브라우저·기기 사용, 사이트 데이터 삭제 또는 비공개 창 종료 시에는 기록이 이어지지 않을 수 있습니다. 로컬 HTML 파일의 저장 정책은 브라우저마다 다를 수 있습니다. Web Locks를 지원하는 브라우저에서는 여러 탭의 회전을 순서대로 처리합니다. Web Locks 미지원 환경에서는 한 탭에서 플레이하세요.

## 개발용 확률 검증

브라우저 개발자 도구 콘솔에서 실행할 수 있습니다.

```js
DangunSlot.simulate(1000000);     // 천장 제외 기본 확률 검증
DangunSlot.simulatePity(1000000); // 30회 천장 적용 연속 플레이 검증
```

기본 횟수는 100,000회이며, 그보다 작은 값은 거부합니다. 각 결과의 빈도·실제 확률·기대 확률을 `console.table()`로 출력하고, 일치 중 단군 비중과 단군을 제외한 상대 비중도 따로 출력합니다. 게임 화면, 저장된 천장 횟수 또는 진행 중 회전을 변경하지 않습니다. `simulatePity()`는 별도의 가상 횟수로 천장 포함 단군 비율·확정 횟수·단군 사이 최대 간격을 출력합니다.

반환 보고서의 `passed`는 모든 검증 확률이 기대값 ±5 표준오차 안에 있고, 불일치 분기의 우발적 3칸 일치가 0건인지 나타냅니다. 유한한 난수 표본의 발생 빈도가 이론값과 정확히 같을 필요는 없습니다.

Node.js가 있다면 게임 폴더에서 아래 명령으로도 검증할 수 있습니다. Node.js는 게임 실행에는 필요하지 않습니다.

```sh
node -e "require('./script.js').simulate(1000000)"
```

제작 시 Chrome·Edge의 로컬 파일 실행, 반응형 화면, 모바일 터치 에뮬레이션, 키보드 및 동작 줄이기 설정을 검증했습니다. 실제 휴대폰과 Safari에서는 테스트하지 않았습니다.
